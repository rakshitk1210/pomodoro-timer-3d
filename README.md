# Pomodoro Timer 3D

An interactive, tactile 3D Pomodoro timer web application built with **React**, **Three.js**, **Tailwind CSS**, and **Vite**.

Inspired by physical desk timers (like the Time Timer), vintage audio cassettes, and hourglasses, this app blends playful 3D interactions with functional focus and study tools.

---

## ✨ Features

- **Interactive 3D Timers**:
  - **Time Timer**: Classic dial-based desk timer with draggable face and physical readout display.
  - **Cassette Tape**: Retro cassette player timer with tape reels and mechanical aesthetics.
  - **Hourglass**: Flowing sand timer visualization.
- **Natural Tactile Controls**:
  - Drag the timer dial/control to set the duration.
  - Drag anywhere else in the scene to rotate and inspect the 3D model.
  - Double-click to snap back to the frontal view.
  - Flick gestures with inertia and sound feedback.
- **Audio & Ambience**:
  - Built-in Lo-Fi background music bed with multiple chill study tracks.
  - Realistic mechanical sound effects (clicks, dial ticks, switch clatter, and chimes).
- **Customizable Appearance & Settings**:
  - Customizable colors, materials, and timer configurations.
  - Thumbnail rail switcher to quickly jump between 3D timer styles.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rakshitk1210/pomodoro-timer-3d.git
   cd pomodoro-timer-3d
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview production build:
   ```bash
   npm run preview
   ```
